## 🚀 Overview

This project automates the process of collecting, summarizing, and delivering the latest Artificial Intelligence and Technology news using n8n and Google Gemini.

The workflow fetches news from multiple RSS feeds, merges and processes the articles, generates concise AI-powered summaries, and automatically sends a well-formatted email to the user. This automation eliminates the need to manually browse multiple news websites while ensuring important updates are delivered on time.

---

## ✨ Features

- Automated daily news collection
- Fetches AI and Technology news from multiple RSS feeds
- Merges and processes news articles
- AI-powered news summarization using Google Gemini
- Automatic email delivery using Gmail
- Scheduled execution with n8n
- End-to-end workflow automation
